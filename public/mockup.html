Aug 2024 – Oct 2024 · Case Study 02

Traffic Signal Optimization using Computer Vision

Edge Vision & Proportional Control
Python OpenCV (MOG2) Flask REST API NumPy Adaptive Timing
Smart India Hackathon 2024 — Level 2 Qualifier

A real-time density-driven traffic control pipeline developed for the Smart India Hackathon (SIH 2024) to replace inefficient fixed-cycle timers with adaptive green light allocations calculated from live intersection camera feeds.

  • Computer Vision Pipeline: Developed OpenCV image processing pipeline leveraging Background Subtractor MOG2 and morphological contour analysis to detect vehicle queues in real time across four intersection legs.
  • Adaptive Allocation Algorithm: Applied dynamic ratio algorithms to compute signal duration: allocating green time proportionally based on instantaneous congestion while enforcing safe minimum crossing floors (10s) and clearance ceilings (90s).
  • Academic Presentation: Co-authored and presented technical findings at BVRIT Engineering College, documenting reduced vehicle idling delays in simulated urban bottlenecks.
